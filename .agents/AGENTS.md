## User Interaction Language

- Always respond in Japanese.

## Comment Principles

- Codes state How.
- Tests state What.
- Commit messages state Why.
- Code comments state Why not (why an alternative was rejected, or why the code cannot be simplified).
- Write no other comments.

## Preferred Commands

When running shell commands, follow these preferences:

- Use `jq` (never `python`) to read and query JSON files.
